# SenTrixWhale

**记忆有大坝,交互有温度** —— 给家庭记忆助手装上人人可用的对话入口。

## 一句话

把组内已经跑通的记忆内核(SHW 2.0)和一套已经验证过的QQ交互套件拼在一起,让记忆助手从工程变成日常随手发一句话、一张照片就能用起来的产品。

## 为什么是现在

AI人格化角色已在各平台自成一景(DeepSeek鲸鱼娘/GPT龙娘/Gemini哈基米...),生态繁荣。但它们有三层递进短板:聊完即忘、沉淀不下来、无法复现。

我们手里正好有两块现成拼图:
- **SHW记忆内核**:VLM caption→多通道索引→Agent检索→QA评测,完整记忆基建;
- **QQ交互套件**:护栏/定量日记/书房/图像识别/防幻觉/视频转文字,全链已验证。

拼起来 = **有记忆、能陪伴、可复现的个人AI**。

## 为什么是QQ

即时通讯是门槛最低的对话入口——不用开网页、不用学命令,发一句话发一张照片,记忆就开始沉淀。

- NapCat/OneBot协议生态存续5年+,社区验证可行;
- 入口可插拔,产品化期可切官方开放API,入口换了记忆不丢。

## 已验证能力(非纸面)

| 能力 | 说明 |
|------|------|
| 费用护栏 | 双计数+日限额,日均0.41元,10元硬顶 |
| 定量日记 | 按对话量自动沉淀小结,每日运行 |
| 书房 | 主人投喂长文,AI主动阅读归档 |
| 图像识别 | 39张同源回归全绿(MiniCPM同批73%) |
| 防幻觉 | 可追溯标准+温度分层 |
| 视频转文字 | 轻量版已跑通,2个B站视频实测 |

## 可验证的记忆

市面陪伴类产品答不了"怎么证明它记对了"这道题。SenTrixWhale把记忆质检做成产品功能:

- **独立信源**:对照物是原始媒体本身,不是AI打分;
- **证据链**:回答附带检索到的原照片/原对话——不是"AI说记得",是"证据在库里,检索出示给你看";
- **用户考鲸鱼**:随时提问,问得出来就是记对了,对错用户自己判断。

## 架构

```
QQ(NapCat) → bridge(对话/护栏/记忆质检) → api(SHW适配器) → SHW 2.0(记忆大坝)
                  ↑                    ↑
              media(入库管线)     storage(本地缓存)
```

模块详情见 [ARCHITECTURE.md](docs/ARCHITECTURE.md)。

## 三阶段路线

| 阶段 | 时间 | 验收 |
|------|------|------|
| 1.对话入口 | 本周 | 手机QQ问"上周拍了什么"→SHW检索回答 |
| 2.媒体入库 | 下周 | 发照片后隔天问细节→回答含原始描述 |
| 3.记忆结构化 | 再下周 | 问"X和Y什么关系"→图谱检索回答 |

失败定义:任一阶段验收不达标→停止推进,复盘归因(不硬推)。

## 模型演进

当前原型跑在DS Flash上(日均0.44元,最快验证产品形态)。长期产品化切端侧Qwen3.5-Q4KM(零成本,自包含)。入口层和记忆层不绑模型,平滑切换。
